# ALIGNMENT 文档: Offer罗盘 - 2026届毕业生求职助手

Offer罗盘是专为2026届大学毕业生打造的AI求职辅助平台，聚焦新质生产力赛道，
提供简历重构、面试模拟、招聘日历三大核心功能。

## 需求理解

### 对现有项目的理解
现有 `index.html` 是一个纯静态单页应用（SPA），包含：
1. 5个页面：首页、简历、面试、日历、个人中心
2. 全部代码（HTML+CSS+JS）集中在单一文件中
3. 使用 Mock 数据模拟 AI 功能
4. 数据持久化使用 localStorage
5. 无后端、无数据库、无用户认证

### 核心功能与数据流
1. **AI简历重构**: 用户输入JD+经历 → 调用AI → 返回重构结果+匹配度评分+关键词分析
2. **AI面试模拟**: 用户选择岗位 → AI出题 → 用户作答 → AI评分+微表情反馈 → 面试报告
3. **招聘日历**: 浏览岗位列表/日历 → 筛选分类 → 查看岗位详情 → 跳转官网

### 数据结构需求
- 用户信息（Auth）
- 简历重构记录（JD、经历、结果、匹配度、时间戳）
- 面试记录（岗位类型、题目、答案、评分、报告）
- 岗位数据（公司、标题、分类、薪资、要求、日期等）
- 使用统计数据
