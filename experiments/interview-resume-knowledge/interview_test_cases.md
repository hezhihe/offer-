# Interview Feedback Test Cases

These cases verify whether the mock interview feature gives concrete, useful feedback.

## Case 1: Invalid Answer

Question:

> 你对目标公司或这个岗位有什么了解？为什么你觉得这个岗位适合你？

Answer:

> 不知道，我不会。

Expected Feedback:

- 切中的点：无
- 没切中的点：没有回答公司理解、岗位理解、个人匹配
- 怎么改：先说岗位核心，再说个人经历，再说能带来的价值

## Case 2: Empty But Polite Answer

Answer:

> 我觉得这个岗位挺好的，我也挺喜欢的，希望能加入。

Expected Feedback:

- 指出表达太泛
- 指出没有公司/岗位理解
- 指出没有个人证据
- 要求补充“做过什么、解决过什么、拿到什么结果”

## Case 3: Has Framework But No Evidence

Answer:

> 我理解低空经济运营需要关注场景、合规、安全和调度。我适合这个岗位，因为我做事认真，也愿意学习。

Expected Feedback:

- 切中：知道岗位关键词
- 没切中：没有真实场景、没有个人动作、没有结果
- 怎么改：补充一个低空物流、巡检、文旅或应急任务场景

## Case 4: Strong Answer

Answer:

> 我理解低空经济运营不是单纯让飞行器完成任务，而是把场景需求、合规边界、安全预案、资源调度和复盘指标串起来。比如如果做园区巡检，我会先确认空域、天气、电池和航线风险，再安排起降点、任务批次和异常处理预案。任务后会记录完成率、异常率、响应时间和用户反馈，用这些数据优化下一轮航线和排班。我适合这个岗位，是因为我习惯把任务拆成流程、风险和指标，并且愿意从一线运营做起，把业务跑通。

Expected Feedback:

- 切中：岗位理解、场景、合规安全、调度、复盘指标
- 没切中：如无真实经历，需要说明是假设方案；可以补个人过往类似经历
- 怎么改：加入一次真实组织、运营、项目或数据复盘经历
